#
# 制表符分隔三列：指令、词/字、音节（音节之间空格分隔）。一行一条指令，
# 同一个词可以出现多行。# 开头是注释。
#
#   fix  该词在生成结果里的全部读音替换为指定读音。用于错音：同词
#        只应有一个读音，底本给错了整个换掉。
#   del  从该词的读音集合里删掉指定的一条。用于同词并存对错两种读音，
#        删错保对（整词替换会把对的也弄丢）。
#   add  给已有词条补一个读音，不动该词已有的其他读音。用于单字缺
#        读音：词组读音（道行 heng）对而单字条目里没有这一读。
#
# 收进来的每条都核对过《现代汉语词典》/《汉语大字典》：
#   - 错音一律指向上游繁体底本的音节串错误，不是简繁转换引入的
#    （转换只逐字换字形，不动音节）。
#   - add 的多是文白异读、方言口语或古语词，只补读，不据此改词形
#    （词形由上游底本决定）。
